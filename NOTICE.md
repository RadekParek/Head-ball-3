# Notice

**Head Ball 3 is original code and original art.** It contains no Head Ball 2 or
Masomo source code, sprites, textures, audio samples, fonts, or other
proprietary assets. Stadiums, characters, balls, icons, particles, the launcher
icon, all sound effects, all crowd noise and all music are generated at runtime
by the game itself or by the small stdlib Python icon script. The APK therefore
ships three web files plus one Java class: no image or audio asset libraries.

Public descriptions of Head Ball 2 were used only as a **feature reference**
while designing an equivalent arcade-football experience. The requested
feature set (90-second 1v1 matches, five-button controls, big-headed heroes,
powers, progression, leagues, cups, penalty duels and so on) is implemented
from scratch with a different visual identity and additional mechanics.
